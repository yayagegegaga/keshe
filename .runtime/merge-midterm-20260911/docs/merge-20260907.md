# 2026-09-07 功能合并说明

来源：用户提供的《流浪动物救助平台 (2).zip》，其中 lachang 项目的业务变更。

## 已合并

- 普通用户与志愿者双注册入口；志愿者填写学号、真实姓名和专业，注册后绑定 VOLUNTEER。
- 首页按角色显示入口及统计，统计卡片可点击跳转；动物列表支持 URL 筛选和重置。
- 志愿者可查看全部任务及详情，领取/完成等写操作仍按原权限与状态校验。
- 线索审核支持查询、快速通过/拒绝、详情弹窗。
- 工单管理支持关键词/状态查询、新建、直接关闭待分配工单、删除待分配工单。

## 合并时修正

- 压缩包遗漏了志愿者字段的 SQL，已补齐新库建表和现有库增量迁移。
- 补齐工单 DELETE 接口及管理员权限、状态校验、日志清理；删除关联工单后，来源线索恢复待审核。
- 待分配工单支持管理员直接关闭并记录日志；原有已分配、处理中、待确认流程继续可用。
- 保留 MEDIUM 紧急程度并增加 URGENT；修正工单状态标签误显示为已取消的问题。
- 修正志愿者注册链接参数未生效、线索详情路由不存在、无权限误报系统错误的问题。
- 保留当前全局主题、首页装饰、登录背景、9 张动物图片与本机数据库连接配置。
